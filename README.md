# Dawit Obsa Kenea — Developer Portfolio

A responsive static portfolio for Dawit Obsa Kenea, a Full-Stack Developer in Addis Ababa, Ethiopia.

## Features

- Responsive mobile-first layout
- Dark/light theme with localStorage persistence
- Accessible navigation and keyboard focus states
- Skills, projects, experience, education, and contact sections
- Contact validation with transparent mailto fallback
- Honest unavailable-demo states
- SEO and Open Graph metadata
- Vercel-ready static deployment

## Run locally

Open index.html directly, or run:

    python -m http.server 8000

Then visit http://localhost:8000.

## Resume

Place the real PDF at assets/resume/Dawit-Obsa-Kenea-Resume.pdf. No fake resume is included.

## Deploy

Push this repository to GitHub, import it into Vercel, leave the build command empty, and use the project root as the output directory.
